To start using Embotic's services, you want to head over to the [Embotic Dashboard](https://dash.embotic.xyz) and create an account. If you have an account skip to the next part.

## Creating an account

1. Head over to the [Embotic Dashboard](https://dash.embotic.xyz).
2. Click the "Create Account" button and fill in your information.
3. Complete the reCaptcha and agree to the [ToS](https://dash.embotic.xyz/terms/tos).
4. Click the "Create Account" button again.
5. Verify your email and connect your Discord account. If you are having any issues, open a ticket on our discord server.

## Creating a server

To create a server on the Embotic Dashboard:

1. Log in to your Embotic Dashboard account.
2. Navigate to the **Servers** section from the sidebar.
3. Click the **Create Server** button.
4. Fill in the required details, such as server name and select your plan. We have multiple plans. Free hosting is only available on the Alpha and Bravo nodes.
5. Review your selections and click **Confirm** to create your server.
6. Once created, your server will appear in the server list. You can manage or configure it further from there.

If you encounter any issues during this process, reach out to support via the Discord server.

For discord bots, select code languages and then the preferred code language.
